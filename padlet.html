🌱 초급 — 대화만으로 수업용 시뮬레이션 만들기

준비물: Claude 계정만 (설치 없음) 예상 소요: 30~40분 결과물: 채팅에서 바로 나오는 링크

코드를 한 줄도 안 봐도 됩니다. "이런 걸 만들고 싶다"를 구체적으로 말로 설명하고, 나온 결과를 보면서 계속 다듬어가는 것이 전부예요.

  1. Claude.ai(또는 앱)에 로그인하고 새 대화를 엽니다.
  2. 프롬프트를 쓸 때 이 4가지를 포함하면 결과가 훨씬 좋아집니다: ① 무엇을(과학 개념) ② 누구를(대상 학년) ③ 어떻게 조작할지(슬라이더/버튼/입력값) ④ 무엇을 보여줄지(그래프/애니메이션/숫자)
  3. 아래 예시를 그대로 복사해서 붙여넣어 보세요.
    중학교 2학년 대상으로 옴의 법칙(V=IR) 시뮬레이터를 만들어줘. 전압과 저항을 슬라이더로 조절하면 전류가 실시간으로 계산되고, 회로 애니메이션이랑 V-I 그래프도 같이 보였으면 좋겠어.
    고등학교 지구과학 수업용으로 태양계 행성들의 공전을 3D로 보여주는 시뮬레이터를 만들어줘. 공전 속도를 조절할 수 있고, 각 행성을 클릭하면 이름과 거리 정보가 나왔으면 해.
    중학교 3학년 화학 수업용 몰농도 계산기를 만들어줘. 용질의 질량과 몰질량, 용액의 부피를 입력하면 몰농도가 계산되고 단계별 풀이 과정도 같이 보여줘.
    고등학교 생명과학 수업용 먹이사슬/개체수 변화 시뮬레이션을 만들어줘. 포식자와 피식자 초기 개체수를 입력하면 시간에 따른 개체수 변화 그래프가 애니메이션으로 그려졌으면 좋겠어.
  4. 결과가 마음에 안 들면 코드를 고치려 하지 말고 "이 부분을 이렇게 바꿔줘"라고 계속 대화하세요. 스크린샷을 그대로 보여주면서 "여기가 이상해"라고만 해도 충분합니다.
  5. 완성되면 화면의 공유/게시(퍼블리시) 버튼으로 링크를 받아, 갤러리에 제출하세요.
💡 팁 처음부터 완벽한 프롬프트를 쓰려 하지 마세요. 일단 대충 요청해서 나온 걸 보고 "이건 되네, 이건 이렇게 바꾸자"로 다듬는 게 더 빠릅니다.

🔧 중급 — 데이터가 쌓이는 진짜 웹앱 만들기

준비물: 구글 계정 + Claude 계정 예상 소요: 40~50분 결과물: 구글시트에 데이터가 쌓이는 웹앱

초급이 "혼자 쓰는" 도구였다면, 중급은 "학생들이 제출하면 데이터가 쌓이는" 도구입니다. 구글 스프레드시트를 데이터 저장소로, Apps Script를 서버로 씁니다 — 서버비 없이 이미 있는 구글 계정만으로 가능해요.

  1. 무엇을 만들지 정합니다. 예: "학생들이 실험 결과나 설문 답을 제출하면 내가 한눈에 볼 수 있는 페이지"
  2. 새 구글 스프레드시트를 만들고, 어떤 항목을 받을지 헤더만 정해서 적어둡니다 (예: 이름, 조, 결과값).
  3. Claude에게 아래처럼 요청합니다.
    구글 스프레드시트를 데이터베이스로 쓰는 학생 제출 페이지를 만들어줘. 학생은 이름, 조, 실험 결과값을 입력해서 제출하고, 나는 다른 페이지에서 제출 현황을 표로 모아볼 수 있어야 해. Apps Script 코드(Code.gs)랑 학생용/교사용 HTML을 각각 줘.
  4. 받은 Code.gs 코드를 스프레드시트 메뉴 [확장 프로그램 → Apps Script]에 붙여넣고 저장합니다.
  5. 오른쪽 위 [배포 → 새 배포] → 유형: 웹 앱 → 액세스 권한: "모든 사용자"로 설정 후 배포. 나온 URL을 복사해둡니다.
  6. 받은 HTML 파일 안에서 그 URL이 들어갈 자리(보통 APPS_SCRIPT_URL이라는 변수)에 붙여넣고 저장합니다.
  7. HTML 파일을 더블클릭해서 브라우저로 열고, 직접 제출해보며 스프레드시트에 잘 들어가는지 확인합니다.
  8. (도전) 생성형 AI 기능도 붙여볼 수 있어요.
    여기에 Gemini API를 연결해서, 학생이 제출한 답을 AI가 자동으로 채점하거나 피드백해주는 기능을 추가해줘.
💡 팁 Apps Script 코드를 다시 고쳤다면 반드시 [배포 → 배포 관리 → 편집(✏️) → 버전: 새 버전]으로 업데이트하세요. "새 배포"를 다시 누르면 URL이 바뀌어서 이미 붙여넣은 HTML과 연결이 끊깁니다.

🚀 고급 — 진짜 인터넷 주소로 배포하기

준비물: GitHub 계정 + Claude Code 예상 소요: 30~40분 결과물: 누구나 접속 가능한 공개 웹사이트

초급·중급에서 만든 결과물은 지금은 내 컴퓨터/내 대화 안에만 있습니다. GitHub Pages에 배포하면 누구나 URL 하나로 접속할 수 있는 진짜 웹사이트가 됩니다. 서버비는 0원이에요.

  1. GitHub 계정이 없다면 github.com에서 무료로 하나 만듭니다.
  2. Claude Code를 열고, 지금까지 만든 파일이 있는 폴더에서 시작합니다.
  3. 이렇게 요청합니다.
    이 프로젝트를 GitHub에 새 저장소로 만들고 GitHub Pages로 배포해줘. 내 GitHub 계정은 (아이디)야.
  4. Claude Code가 저장소 생성 → 커밋 → 푸시 → Pages 활성화까지 순서대로 대신 해줍니다. 중간에 로그인/인증이 필요하면 안내하는 대로 따라가면 됩니다.
  5. 1~2분 뒤 https://(아이디).github.io/(저장소이름)/ 주소로 접속해서 확인합니다.
  6. 이후 수정하고 싶으면 "이 부분을 이렇게 고쳐서 다시 배포해줘"라고 하면 자동으로 반영됩니다.
💡 팁 배포 직후 화면이 안 뜨면 1~2분 기다렸다가 새로고침 해보세요 — GitHub가 사이트를 빌드하는 데 시간이 걸립니다.
